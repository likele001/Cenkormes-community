# 后端模块总览

位于 `backend/app/`，按职责分层：

## 目录职责
```
backend/app/
├── api/        路由层（收到请求→鉴权→调服务/crud→返回）
│   ├── router.py         总入口，显式注册所有子模块 include_router
│   ├── admin/            管理后台（master/production/erp/finance/warehouse/...）
│   ├── h5/               员工端 H5（report_units/tasks/attendance/salary_slips/customer）
│   ├── miniapp/          微信小程序（auth/subscribe）
│   ├── v1/               认证/文件/租户/推送监控
│   ├── platform/         SaaS 平台（auth/tenants/packages/ai/storage）
│   ├── ws/                websocket（dashboard 实时）
│   └── feishu|wecom|dingtalk/   开放回调
├── models/     SQLAlchemy 模型（81 文件，models/__init__.py 集中导出）
├── schemas/    Pydantic 请求/响应
├── crud/       数据访问层（查询封装）
├── services/   业务服务：abac、workflow、ai、ai_employee、feishu/wecom/dingtalk 推送
├── core/       框架：config、db、deps、security、redis_client、response、errors、seed
├── schedulers/ 定时任务
├── tasks/      Celery 异步任务
├── industries/ 行业包（food/auto_parts/electronics/injection_molding/garment/machining）
└── main.py     FastAPI 入口
```

## 核心组件说明
| 组件 | 文件 | 作用 |
|------|------|------|
| 数据库会话 | core/db.py | AsyncSession 依赖 get_db |
| 鉴权依赖 | core/deps.py | get_current_user / require_admin_portal_user / require_permissions |
| 安全 | core/security.py | hash/verify_password、create/decode_token |
| 响应 | core/response.py | 统一成功/错误封装 |
| 限流 | core/redis_client.py + middleware | per-endpoint 内存滑动窗口限流 |
| 版本 | core/seed.py / system_version | 启动同步 CHANGELOG→system_versions |
| AI 网关 | services/ai | 多模型渠道网关 /chat/completions、冷却、熔断 |
