## 新增迁移硬性规范
1. **幂等**：`sa.inspect(op.get_bind()).has_table(...)` 判断后再 create_table
2. **revision ≤ 32 字符**（`alembic_version.version_num` 是 varchar(32)）
3. 迁移文件**双路径**放置：全局 `backend/alembic/versions/` + 各 app 自身 `alembic/versions/`（保证安装包完整）
4. 模型与表字段**完全一致**（含软删 deleted_at），否则查 `UndefinedColumnError`
5. 线上已存在库补列用 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`
