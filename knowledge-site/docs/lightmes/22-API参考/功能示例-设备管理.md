# 功能示例 · 设备管理（/admin/equipment）

> 说明：本文为「如何写接口详细文档」的样例，含真实签名与字段。其余模块见 [README-接口总索引](README-接口总索引.md)，逐个补齐即可。
> 实现文件：`backend/app/api/admin/equipment/router.py`、`schemas/equipment.py`；表 `equipment`。

## 资源路径
模块前缀 `/api/admin/equipment`，管理后台鉴权 `require_admin_portal_user`，租户隔离。

## 接口一览
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/equipment` | 分页列表 |
| GET | `/equipment/export` | 导出 |
| POST | `/equipment` | 新增 |
| PUT | `/equipment/{equipment_id}` | 编辑 |
| POST | `/equipment/{equipment_id}/check` | 点检 |
| GET | `/equipment/{equipment_id}/checks` | 查点检记录 |
| GET/POST | `/equipment/maintenance-plans` | 保养计划 列表/新增 |
| PUT/DELETE | `/equipment/maintenance-plans/{plan_id}` | 保养计划 编辑/删除 |
| GET/POST | `/equipment/maintenance-logs` | 保养记录 列表/新增 |

## 请求/响应字段

### 新增 equipment（POST /equipment）
请求体 `EquipmentCreateIn`（schemas/equipment.py:7）：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string ≤32 | 否 | 设备编码（缺省时自动生成，唯一性校验 `_equipment_code_exists`） |
| name | string 1–128 | 是 | 设备名称 |
| model | string ≤64 | 否 | 型号 |
| workshop | string ≤64 | 否 | 车间 |
| remark | string | 否 | 备注 |

### 编辑 equipment（PUT /equipment/{id}）
`EquipmentUpdateIn`（:15）额外支持：`status`、`purchase_date`、`last_maintenance_date`、`next_maintenance_date`、`maintenance_interval_days`。**注意 date 型不能直接绑 str**，需 `datetime.strptime` 转换。

### 返回 EquipmentOut（:28）
含 `id/tenant_id/code/name/model/workshop/status/purchase_date/last_maintenance_date/next_maintenance_date/maintenance_interval_days/remark/created_at/updated_at`。

### 保养计划 EquipmentMaintenancePlanCreateIn（:47）
`equipment_id / plan_type(daily|weekly|monthly) / check_items(检查项JSON) / interval_days / responsible_user_id / next_date`

## 注意事项
- 列表查询 `WHERE tenant_id = 当前租户`
- `{equipment_id}` 等路径参数做整数/存在性校验
- 涉及型号/保养日期等敏感字段返回前走 `mask_rows` 统一脱敏
