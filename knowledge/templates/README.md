# 文档模板工具集
新写任何知识库文档，先复制对应模板再填内容。

| 模板 | 用途 |
|------|------|
| [文档模板.md](文档模板.md) | 通用文档头（状态/更新人/关联） |
| [API接口模板.md](API接口模板.md) | 记录一个后端接口 |
| [数据模型模板.md](数据模型模板.md) | 记录一个数据模型/表 |
| [踩坑记录模板.md](踩坑记录模板.md) | 记录一次问题排查 |

规范要点：
- 商业文案用 CenkorMES
- 新增依赖需同步 THIRD_PARTY_NOTICES.md
- 敏感字段注明走 mask_rows 脱敏
