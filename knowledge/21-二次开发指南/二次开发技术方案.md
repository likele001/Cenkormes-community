## 2. 路由怎么注册（新增 API 的入口）

**机制（实测）**：在 `backend/app/api/router.py` **显式 import + include_router**，非自动扫描。

```python
# backend/app/api/router.py（新增片段）
from app.api.admin.xxx.router import router as admin_xxx_router

admin_xxx_router.include_router(
    admin_xxx_router,
    prefix="/admin/xxx",          # 统一前缀
    tags=["admin-xxx"],
    dependencies=[Depends(require_admin_portal_user)],  # 后台鉴权
)
```

**前缀约定**：
- 管理后台 → `/admin/*`（deps: `require_admin_portal_user`）
- 认证/文件 → `/auth`、`/files`、`/tenants`
- 员工/移动 → `/h5/*`、`/miniapp/*`
- 开放回调 → `/feishu`、`/wecom`、`/dingtalk`
- 实时 → `/ws`

> 新增模块的两件事：① 建 `api/admin/xxx/router.py` 并定义 APIRouter；② 在 `router.py` 注册。**别漏第二步**，否则接口 404。

## 4. 场景二：新增数据模型 + 迁移（Alembic 规范）

**迁移链**：`backend/alembic/versions/0001_init.py → 00xx`，当前到 0030+。新增编号续 `0031_xxx.py`。

**硬性规范（必须遵守）**
1. **幂等**：`sa.inspect(op.get_bind()).has_table("wf_maintenance")` 判断后再 `create_table`
2. **revision id ≤ 32 字符**：`alembic_version.version_num` 是 `varchar(32)`，超长报 `StringDataRightTruncation`
3. **迁移文件同时放两个位置**：
   - `backend/alembic/versions/`（本库）
   - 若属 ERP 域：`backend/app/erp/alembic/versions/`（安装包完整性）
4. **模型与表字段完全一致**（软删除 `deleted_at` 等列别漏，否则查 `UndefinedColumnError`）
5. **为线上已存在的库补列**：用幂等 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`，不依赖链表

```python
# SPDX-License-Identifier: AGPL-3.0
from alembic import op
import sqlalchemy as sa
revision = "0031_workorders"
down_revision = "0030_task_assignments"

def upgrade():
    if not sa.inspect(op.get_bind()).has_table("wf_maintenance"):
        op.create_table("wf_maintenance",
            sa.Column("id", sa.String(36), primary_key=True),
            sa.Column("tenant_id", sa.String(36), nullable=False),
            sa.Column("issue_desc", sa.String(500)),
            mysql_engine="InnoDB",
        )
```

## 5. 场景三：权限、租户隔离、脱敏（改动功能必守）

### 5.1 租户隔离（每个接口必须做）
- 创建数据：强制写入当前 `user.tenant_id`，绝不信任请求体里的租户字段
- 查列表/详情：所有查询 `WHERE tenant_id = <当前租户>`，防跨租户取数

### 5.2 UUID 参数校验
```python
import re
if not re.fullmatch(r"[0-9a-fA-F-]{36}", uid):
    raise HTTPException(400)   # 防止 string_to_uuid 报错
```

### 5.3 列脱敏（ABAC）
- 敏感列（电话/金额/工资条）统一走后端 `AppAbacEngine` 的 `mask_rows(resource, rows)` 脱敏
- **小程序/前端不再做脱敏逻辑**，只展示后端已脱敏结果 → 改一个规则不用重新发版

### 5.4 并发与事务
- 减库存/扣款：`select(...).with_for_update()` 锁行防并发
- 改 ORM 属性或 `db.add` 新对象：**必须 `await db.commit()`**，否则静默回滚
- `Numeric` 字段是 `Decimal`，累加需 `float()` 转换，防 `TypeError`

## 6. 前端二次开发

以 `frontend-admin-pro`（Vue3 + Vite5）为例：
- 页面放 `src/pages/`，路由在 `src/router/`，API 封装放 `src/api/`
- 存储 key 用 `cenkormes_` 前缀（不是 `lightmes_`）
- 自定义 HTTP 头用 `X-CenkorMES-Portal`
- 引第三方库改 `package.json` 后要在 `THIRD_PARTY_NOTICES.md` 声明及license
- **小程序端**：
  - 隐私接口（相机/相册/麦克风）需在微信公众平台"用户隐私保护指引"声明，避免真机被拦截
  - `app.json` 的 `permission` 只认 `scope.userLocation`，其它在真实调用时自动弹授权
  - 语音输入用 WechatSI 插件（appid `wx069ba97219f66d99`），不可用时回退手动输入

## 9. 高频踩坑速查（来自本项目经验）

| 症状 | 根因 | 修法 |
|------|------|------|
| `MissingGreenlet` | 序列化嵌套关系未预加载 | 查询 `.options(selectinload(ErpCustomer.contacts))` |
| `PydanticSerializationError: Unable to serialize unknown type` | Out schema 嵌套字段用了 `list[Any]` | 用专用 Out schema `list[XxxItemOut]` |
| `UndefinedColumnError: X.deleted_at` | 建表迁移漏列 | 幂等 `ADD COLUMN IF NOT EXISTS` |
| `str object has no attribute toordinal` | Date 列绑 str | `datetime.strptime(...)` 后再存 |
| `TypeError: '+=' ... Decimal` | Numeric 未转 float | `float()` 转换 |
| 接口"成功"但库没变 | 漏 commit | 显式 `await db.commit()` |
| 502 `all upstreams failed` | 漏 await / URL 拼错 | 检查协程 await、base_url 拼接 |
