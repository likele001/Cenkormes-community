# 总体架构

> CenkorMES(LightMes) 是一款多租户 SaaS 轻量化生产管理系统。前后端分离，后端 FastAPI。

## 分层视图
```
                 ┌──────────────────────────────────────────┐
                 │  前端（多端）                              │
                 │  frontend-admin-pro(管理) · h5(员工端)     │
                 │  frontend-portal(门户) · lightmes-miniapp  │
                 └───────────────┬──────────────────────────┘
                                 │ HTTP(S) / JWT  / HttpClient
                 ┌───────────────▼──────────────────────────┐
                 │  后端 FastAPI  (backend/app)             │
                 │  api(路由) → crud/services(业务)          │
                 │  core(鉴权/配置) · schemas(校验)          │
                 └───┬───────────┬───────────┬──────────────┘
                     │           │           │
              ┌──────▼───┐ ┌─────▼─────┐ ┌───▼─────┐
              │ PostgreSQL│ │  Redis    │ │ Celery  │
              │(业务+ERP) │ │(缓存/锁/限流)│ │(异步/定时)│
              └──────────┘ └───────────┘ └─────────┘
```

## 关键设计
- **多租户隔离**：所有业务表带 tenant_id，查询强制按当前租户过滤（见 03-SaaS多租户隔离）
- **统一鉴权**：JWT + 依赖注入（require_admin_portal_user / require_permissions）
- **ABAC 数据权限**：行级 scope 过滤 + 列级脱敏 mask_rows（见 02-权限与ABAC）
- **多消息渠道**：飞书/企微/钉钉/公众号 推送，各自 push_log 表记录（见 04-消息推送架构）
- **社区/商业并行**：community 与 pro(pro-build) 双代码线，靠 split-packages 拆分

## 技术栈
| 层 | 选型 |
|----|------|
| 后端 | FastAPI(ASGI) · SQLAlchemy2(Async) · Alembic · Pydantic · Redis · Celery |
| 前端 | Vue3 + Vite5（4 端口） |
| 数据库 | PostgreSQL |
| 认证 | JWT + bcrypt |
