# 0002- 接口"成功"但数据库没变
- 日期：2026-09
- 模块：后端 FastAPI 端点
- 严重度：🔴 高
- 状态：已解决

## 症状
接口返回看似成功（返回体是硬编码成功 dict），但数据库字段没更新、新记录不存在。

## 根因
FastAPI 异步端点内修改 ORM 属性或 `db.add()` 新对象后，若漏 `await db.commit()`，请求结束整体回滚——一切将被撤销。

## 解决方案
修改查询出的 ORM 属性、以及 `db.add` 新对象之后，**必须显式 `await db.commit()`**。

## 涉及文件
- 所有含写操作的端点（改状态、add 记录）

## 预防
写操作端点固定三步：改/add → `await db.commit()` → 返回。
